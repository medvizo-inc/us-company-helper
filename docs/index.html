US Company Helper

Free Chrome extension

Your US company's details, one click to copy.

Running a US company from abroad means typing the same EIN, address and phone number into bank forms, Stripe, Amazon and tax forms again and again. Keep them in your browser and copy each one with a click.

Install it View the source on GitHub

What it holds

  • Company name
  • EIN, set out as 12-3456789 when you type nine digits
  • Corporate address
  • US phone number
  • Up to 20 fields of your own, such as a state filing ID or your registered agent's name

Install

The Chrome Web Store listing is in review. Until it is live, load it from this repository:

  1. Download the repository as a ZIP from GitHub and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and choose the extension folder.
  4. Pin it from the puzzle-piece menu.

Your details stay on your computer

The extension saves only to your browser's local storage. It makes no network requests, has no account, and asks for one permission, storage, so it can't read or change any website. Removing the extension deletes what you saved. The full privacy page says the same in more detail, and the source is short enough to read.

Questions

Where do I get an EIN if I don't have a Social Security Number?
The IRS issues one to a foreign-owned company on Form SS-4, by fax or phone. BaseAcross has a guide: getting an EIN without an SSN.
Can I use my registered agent's address as my corporate address?
Only as the company's legal address with the state. Banks such as Mercury don't accept it as the business's address. More in what a registered agent does.
Does it sync between computers?
No. It uses local storage on purpose, so your details never leave the computer you typed them on.
